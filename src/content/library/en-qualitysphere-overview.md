## Project introduction

QualitySphere is a Smartscity engineering-quality and integration-testing project. This public guide provides an introduction and an evaluation contact path. A publicly verified installation and release guide is not available in the portal's current evidence set.

## Prepare a useful evaluation request

Describe the test project and runtime, environment preparation, parameter ownership, execution responsibilities, and how your team reviews results. Identify the versions and access conditions that an evaluation must cover. Ask for the applicable distribution and its setup, Runner, report, permission, and troubleshooting instructions before treating a workflow as ready for your environment.

## Agree what a result proves

Separate test execution from a human release decision. Agree which source revision, environment, and scope a report must identify, and how failures, skipped work, and unavailable evidence should be represented. These are evaluation questions, not claims that every workflow has been publicly released.
