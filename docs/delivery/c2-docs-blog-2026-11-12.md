## Delivered scope

24 localized readings: nine Docs and three Blog articles in each language. The three Chinese source articles retain their complete arguments, qualifications and references, with full English adaptations. English is the default; English visible text is scanned for Han characters. Original green editorial covers with English headlines appear on cards and article pages; PNG exports supply social metadata.

Core engineering products are HyperRaft, QualitySphere and ReconSphere. The homepage and Docs reuse the same catalog. AI Agent Reliability is listed separately as an assessment service. Starter remains in other components; its three guide URLs remain stable. Original project, company, Contact and ecosystem destinations are retained.

The static content collection owns stable IDs, locale, product, section, version, author, updated date, source revision and related readings. A single publication policy excludes draft/review content before routes, lists, search or related links are generated and rejects inconsistent translations and broken related references. Only populated sections appear. One available edition is displayed as a version label; there is no empty selector.

Reading features include desktop side navigation and TOC, mobile disclosures, breadcrumbs, full-text local search with content/product/topic filters, URL-restored search, empty/reset states, code copying with real failure handling, scrollable tables/code, previous/next links, sources, related readings and a contextual mailto. The receiving address is read from `company.ts`. No form backend, fake submitted state, subscriber list, analytics, CMS or account was introduced.

## Architecture review

The publication rule is a pure policy with a thin Astro adapter. Views compose shared catalog/contact components; there is no class hierarchy or global state. Search and clipboard listeners belong to a document and disappear on normal navigation. Search is bounded by the published collection and query length; no request or user HTML injection occurs. SiteLayout gains navigation and optional social-image metadata, not editorial or search state. Existing city/demo state owners remain intact.
