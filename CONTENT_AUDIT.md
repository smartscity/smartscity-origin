## Names and licenses

The public product name is **Polarbear Vocab**. The architecture documentation names its knowledge component **Polarbear Lexicon**. `VocabProbe` is not used as the public product name. Polarbear and Polarbear Vocab are separate repositories and apps; documented macOS integration does not make them one application.

Polarbear provides [LICENSE-MIT](https://github.com/smartscity/polarbear/blob/main/LICENSE-MIT) and [LICENSE-APACHE](https://github.com/smartscity/polarbear/blob/main/LICENSE-APACHE), with `MIT OR Apache-2.0` in the README. Polarbear Vocab's [Cargo.toml](https://github.com/smartscity/polarbear-vocab/blob/main/Cargo.toml) declares MIT, but a root license text was not found and GitHub license metadata was null. The portal states this limitation rather than declaring a complete license audit.
